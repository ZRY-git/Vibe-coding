## 一、一句话说明

一个把「学英语」做成 PvE 爽游的网站：学习获得体力与装备，角色随之变强；用户自定目标、自主完成、玩得爽——不用怕扣血、掉段或被逼中断。

## 二、要解决的麻烦

- **目标用户**：正在学英语、但坚持不下去的人（学生、备考者、想捡起英语的上班族）。
- **使用场景**：每天想花十几分钟学英语，但一个人学没有对手、看不到乐趣。
- **痛点陈述**：市面上的英语学习产品，「进步」的反馈冰冷无趣，缺少竞争动力与个性化——一个人学没有对手，坚持不过几天。
- **现有做法为何不够**：主流产品要么把反馈做成冷冰冰的进度条与正确率，要么用打卡天数制造压力（断签反而更不想打开）；游戏化做得最彻底的产品，竞争对象是系统随机分配的陌生人，与你日常在意的人无关。

## 三、三个类似产品比较

| 维度 | 多邻国 Duolingo | 扇贝单词（国内） | Wordle（每日一题） |
|---|---|---|---|
| 解决什么麻烦 | 让学语言变成每天忍不住打开的闯关游戏 | 背单词难坚持，用打卡和同伴监督逼出习惯 | 每天一道 5 字母猜词，给早晨一个三分钟小仪式 |
| 谁在用 | 全球泛学习者，门槛低 | 国内考试备考生（四六级、考研） | 全世界打工人与学生，没有学习目的也能玩 |
| 游戏机制 | 连胜 + 经验值 + 红心（生命值）+ 宝石 + 段位联赛排行榜 | 连续打卡天数好友可见、小组互相监督、支持自建词书 | 每日一题（全球同一题）+ 无剧透的分享网格 |
| 做得好 | 机制最齐全，留存极强，把「让用户回来」做到最好 | 打卡与熟人可见的社交压力确实有效；支持个性化词书 | 靠分享格子零成本引爆社交传播；有限制反而不腻 |
| 不足 | 竞争是与随机陌生人打段位赛，不是与好友比；为保段位刷经验使学习变味；答错扣心、宝石回血被批制造焦虑与内疚；识别练习不等于真正会用 | 断签有负面心理效应；复习量越滚越大、越背越焦虑；免费版广告影响体验 | 每天只能玩一次，无法反复练，不适合系统学习 |
| 对我们的启发 | 体力、装备、排行榜这些机制它全都有——照抄机制没有意义 | 熟人之间的比较最有效；个性化词书是刚需 | 比较不一定要排行榜：晒「怎么做到的」比晒名次更有话题性 |

补充参考（**待核实**）：百词斩有「单词 PK 对战」，被用户评价的硬伤是「记住图片忘了词」；沪江开心词场有「闯关 + 好友组队 PK」。此两条来自二手汇总文章，未逐一实测。

## 四、研究结论与差异化

1. **机制不是护城河**：我们最初设想的体力、装备、排行榜，多邻国已经全部实现。价值不在「也做一个」，而在「做得不一样」。
2. **竞争方式要换**：多邻国的竞争是与系统随机分配的陌生人打段位赛（还有降级压力）。我们改为轻量的 PvE 分数周榜 + 每周称号，只升不降、不进榜也没有惩罚。
3. **反馈方向要反着来**：多邻国用「答错扣心、花宝石回血」制造稀缺与惩罚；我们坚持正反馈养成——完成学习就获得体力与装备，角色变强，绝不中断用户。
4. **个性化是缺口**：学习内容允许自定（背自己真正要背的词），装备与称号也允许自定义，而不只是换皮肤。

### 差异化假设（已确认）

- **假设 A**：不做陌生人段位赛，做小圈子/轻量排行榜——只升不降，比较对象是可自选的。
- **假设 B**：资源用正反馈养成（学得好 → 得体力/装备 → 角色变强），不做扣血、复活、降级这类惩罚式中断。
- **假设 C**：个性化落在学习内容与称号、装备上，让用户能表达「我是谁」。

### 立项原则（Day 3 反思，本项目的第一性判断）

作者原话（Day 3 反思题）：

> 「原本我想产品的竞争力在于游戏创意，现在才发现从用户出发才是对的。轻量化、无压力、正反馈、社群娱乐，才是英语学习软件最先确定的，而不是游戏开发式的自嗨。」

由此确立两条上位原则，**今后所有设计决策先过这两条，再谈实现**：

1. **先定用户与体验，再定玩法**——「轻量化、无压力、正反馈、社群娱乐」这四条是所有功能的约束条件，不是可选项。
2. **游戏不是入口，是出口**——用户为学英语进来，为「看见自己变强」留下；打怪只是把「进步」变得可以摸到的方式。游戏不与真正的游戏竞争，只服务于学习闭环。

这条原则同时解释了本文档里的既有决策为什么是这样：

- **不做扣血、复活、降级**——惩罚机制是「留住游戏玩家」的手段；我们要留的是学习者，方向必然相反。
- **正反馈养成、自定目标**——让进步可感知、可自主，而不是被系统推着走。
- **每周玩梗称号而非名次压力**——社群娱乐要的是话题，不是焦虑。

## 五、产品概念雏形（v0）

**核心闭环**

1. 用户自定学习目标（例如每天若干词/若干题）
2. 完成学习与答题 → 获得体力、装备等道具
3. 道具用于强化角色
4. 角色变强 → 进入横版场地刷怪（怪从左右两侧来、越打越强）→ 累积 PvE 分数
5. 每周依据 PvE 分数评选称号，用户可自选称号发布

**每周称号机制**

- 每周评选「手法王」「学习王」等称号，依据 PvE 分数
- 用户可以**自选称号**，用来调侃自己夺冠的原因（把炫耀变成玩梗，延续「零压力竞争」）
- 目的：让比较变成话题，而不是压力

**战斗玩法设计（v0，作者补充）**

- **视角**：2D 横版（参考泰拉瑞亚的战斗手感）——有重力、可跳跃，敌我在同一个平面里对抗
- **画面**：2D
- **场景**：只有一个区域——单一场地，不做地图探索
- **刷怪方式**：怪物**只从左右两侧**进场，分两类：
  - **陆军**：在地面行走，受地形与重力限制
  - **空军**：在空中飞行，跨越地面障碍，从上方压迫玩家
- **难度曲线**：击杀越多，后续刷出的怪越强（无尽递增）

| 设定项 | 内容 |
|---|---|
| 视角 | 2D 横版（有重力、可跳跃） |
| 画面 | 2D |
| 场景 | 单一场地（一个区域） |
| 刷怪 | 只从左右两侧进场 |
| 敌人类别 | 陆军（地面）+ 空军（飞行） |
| 难度 | 随击杀数递增，越打越强 |
| 角色强度来源 | 学习获得的体力与装备，直接体现在战斗表现上 |

**这样设计好在哪（本次研究的判断）**

1. 「杀得越多、怪越强」本身就是一套天然的无尽模式：**分数 = 你撑到第几波 / 杀了多少**，PvE 分数由此而来，直接对接每周称号机制，不需要另造一套计分规则。
2. 「只从左右两侧进场 + 单一场地」把关卡成本压到最低：不需要地图、不需要复杂寻路，怪物沿一条线进场即可，一个场地就能无限玩下去。
3. **「陆军 + 空军」的选择是本设计里性价比最高的一笔**：陆军逼你处理脚下走位与跳跃时机，空军逼你不能只盯着地平线看。两者只需两套最简单的移动逻辑，却让「先打谁、往哪躲」产生真实取舍——这正是爽游「越打越有手感」的来源，也是机制上最容易做出差异的地方（对比多邻国式的选择题，它没有这类操作空间）。
4. 学习与战斗形成闭环：**学习 → 体力/装备 → 战斗中更强 → 分数更高 → 称号**。学英语的成果会在战斗里被直观感觉到，这正是「让进步变得具体有趣」的落点。

**装备创意**（作者补充，待填）

> 装备创意的具体条目由作者后续补充。设计方向已明确：装备从学习成果中获得（正反馈养成），用于强化角色、提升战斗表现；不做合成、交易与稀有度分级（见「本期不做」清单）。

**战斗系统的本期最小切片**（避免范围膨胀）

| 本期要做 | 本期不做（详见第六节） |
|---|---|
| 一个横版场地、一个角色（移动 + 跳跃 + 一种攻击）、怪物从左右两侧进场、陆军与空军各一种、随击杀变难、死亡即结算可立刻重来 | 地图探索与多关卡、多武器切换、技能树、Boss 战、装备掉落随机性、多种地形与平台编辑 |

**本期榜单的技术现实**：真实的全服/好友周榜需要账号系统与后端数据库，二者均在本期不做清单内。本期先用本地记录跑通机制与界面，真实榜单等数据库阶段再做。

## 六、本期不做清单

| 不做的事 | 理由 |
|---|---|
| 账号注册与登录 | 本期先做本地单机体验，机制跑通比账号重要 |
| 好友系统与真实多人榜单 | 依赖账号与后端，本期用本地记录代替 |
| 数据库 | 计划在后续阶段引入，本期数据存浏览器本地 |
| 多语种、多学科 | 只做英语一个方向，做深比做广有价值 |
| 多职业、多皮肤系统 | 角色养成先做一条线，避免美术与逻辑爆炸 |
| 地图探索与多关卡、可编辑地形 | 本期只有一个固定横版场地，够玩即可 |
| 多武器切换、技能树、Boss 战 | 只保留一种攻击方式；先验证「打得爽」，再谈丰富度 |
| 装备掉落随机性 | 装备由学习成果确定性发放，不做刷宝随机 |
| 装备合成、交易、稀有度分级 | 属于深度系统，本期只需「获得 → 变强」 |
| 组队副本、多人 Boss | 需要实时通信与后端，本期是单机 PvE |
| 移动端适配与 App 打包 | 先做网页版，能在电脑浏览器打开即可 |
| 支付、内购、商城 | 无商业化计划，不引入任何付费点 |
| AI 自动出题、智能纠错 | 内容先用固定题库，避免不确定性 |
| 语音识别与口语打分 | 技术成本高，与本期核心闭环无关 |

一句话边界：**本期只做「答题 → 得装备 → 角色变强 → 单场地刷怪得分 → 本地记录分数」这一个闭环，其他都不做。**
