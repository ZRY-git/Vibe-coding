## 一、产品概述

**一句话**：一个把「学英语」做成 PvE 爽游的本地网页——完成学习获得体力与装备，角色变强后在横版场地刷怪得分，凭分数解锁每周玩梗称号；只升不降，没有任何惩罚中断。

**本文档回答两件事**：做成什么样（第三章功能需求）、怎么算做完（第五章验收标准）。

**本期定位**：本地单机网页版。跑通最小闭环——**答题 → 得装备 → 角色变强 → 单场地刷怪得分 → 本地记录分数**。真实账号、真实好友榜单等均不在本期（见第四章）。

## 二、用户与场景

- **目标用户**（继承 research.md）：正在学英语、但坚持不下去的人（学生、备考者、想捡起英语的上班族）。
- **核心场景 1 · 每天十几分钟**：打开网页 → 主页看到角色状态 → 答一组题 → 看到体力/装备到账 → 进战斗爽一局 → 结算页看到分数上涨。
- **核心场景 2 · 每周玩梗**：周末看本周累计分对应的称号档位，自选一个称号挂在主页调侃自己。
- **设计约束**（继承立项原则，所有功能验收前先过这四条）：轻量化、无压力、正反馈、社群娱乐。

## 三、功能需求

本期共 3 个页面：**主页**（角色状态 + 分数 + 称号）、**学习页**（答题）、**战斗页**（横版战斗）。以下 P0 为本期必须完成；P1 为有余力才做，不做不影响验收。

### P0-1 学习与答题（学习页）

1. 主页点击「开始学习」进入学习页；可自定本次目标词组（从内置词库选择，默认一组 5 题）。
2. 出题形式：单词 → 释义，四选一选择题，全部出自内置固定词库。
3. 答对：立即提示奖励到账（体力 +N / 装备发放）；答错：显示正确答案后继续，**不扣除任何已有资源**（正反馈原则）。
4. 完成一组后进入结算页：显示本组获得体力与装备，点击「进入战斗」或「返回主页」。

### P0-2 角色与装备（主页展示）

1. 角色属性面板：体力、攻击力、已获得装备列表。
2. **体力**：学习的核心产出。每完成一组学习体力 +5（初值）；体力为战斗强度提供加成——体力越高，角色在战斗中越强。具体换算公式属开发细节，但必须满足第五章 A5（学得越多、打得越轻松）。
3. **装备**：从学习成果**确定性发放**（无随机）。示例装备：**力量手套（攻击力 +1）**——每完成一组学习必得一件，可叠加。装备获取后立即在主页属性面板生效。
4. 角色属性只增不减：不存在扣属性、降级、回收装备。

### P0-3 横版战斗（战斗页）

1. **场景**：2D 横版单一场地，有重力、可跳跃；不做地图探索。
2. **操作**：键盘——左右移动、跳跃、攻击（仅一种攻击方式）。
3. **刷怪**：怪物只从左右两侧进场，两类各一种：
   - **陆军**：在地面行走，受重力限制；
   - **空军**：沿固定高度匀速直线横飞（本期最简实现）。
4. **难度曲线**：按击杀数分波——每波 5 只（初值），击杀满本波数量进入下一波；波数越深怪越强（血量/速度/数量提升，具体数值开发期定），无尽递增。
5. **计分**：单局得分 = 该局击杀怪物总数；同时记录撑到第几波，结算页展示。
6. **战败规则**：角色被击败 → 本局结束 → 结算页显示分数/波数/击杀数 → 可立刻重开。战败**零损失**：已得体力、装备、历史记录全部保留（本局有生命值，但生命值只决定单局长度，与学习资产无关）。

### P0-4 分数记录（主页）

1. 每局结束后，分数、波数、击杀数、日期写入浏览器本地存储。
2. 主页展示：最高单局分、本周累计分（按自然周，周一为起点自动重置）。
3. 刷新或关闭浏览器后记录不丢失。

### P0-5 每周称号（主页）

1. 称号按**本周累计分**档位解锁（初值两档：50 分解锁「学习王」、150 分解锁「手法王」），解锁后永久保留。**与 research.md 的差异说明**：原设定「每周依据分数评选称号」需要比较对象与后端支持（本期不做，见第四章），本地版以「档位解锁」替代——达成即得、玩梗性质不变；真实评选留到账号与后端阶段实现。
2. 用户可自选 1 个已解锁称号展示在主页；允许自定义称号文字（玩梗需要，延续「比较变成话题」）。

### P1（有余力才做，不影响验收）

- P1-1 战斗手感细节：击杀连击数展示、打击停顿。
- P1-2 音效：攻击命中与结算音。
- P1-3 答题页动画与正确率统计。

## 四、本期不做清单

> 本章与第五章配合使用：自检与验收时，凡发现清单内功能出现在需求或实现中，即判定范围膨胀。完整理由见 research.md 第六节，此处收录全部条目并展开三个代表案例。

**三个代表案例（今天的核心砍功能决策）**：

| 砍掉什么 | 为什么砍 | 挂到哪条原则 |
|---|---|---|
| 账号系统 + 真实好友周榜 | 真实榜单需要账号与后端数据库；机制（分数好玩吗、称号有话题吗）尚未验证前先不背基建成本。本地记录足以验证核心闭环 | 轻量化 |
| 装备合成 / 交易 / 稀有度分级 / 随机掉落 | 「获得 → 变强」单方向已支撑闭环；刷宝与养成深度是第二个游戏，与「先验证打得爽」冲突 | 轻量化、无压力 |
| Boss 战 / 技能树 / 多武器切换 | 单一攻击先验证手感；砍掉后美术与数值工作量降一个量级，避免范围膨胀拖死本期 | 先定体验再定玩法 |

**完整清单**（理由详见 research.md 第六节）：账号注册登录；好友系统与真实多人榜单；数据库（本期数据存浏览器本地）；多语种多学科；多职业多皮肤；地图探索与多关卡、可编辑地形；多武器切换、技能树、Boss 战；装备掉落随机性；装备合成、交易、稀有度分级；组队副本与多人 Boss；移动端适配与 App 打包；支付、内购、商城；AI 自动出题、智能纠错；语音识别与口语打分。

## 五、验收标准

> 全部为可判定条目；数值为初值，调整时须同步更新本章。AI 自检与收尾核对以本章为评分表。

**总体**

- A0：电脑浏览器打开网站即用，无报错，学习→战斗→结算→主页全流程**无需任何登录**。

**学习与答题**

- A1：主页点击「开始学习」后 3 秒内进入答题界面。
- A2：完成一组学习（5 题）后出现奖励结算，体力与装备到账，主页属性面板立即可见变化。
- A3：答错时展示正确答案，且体力、装备、分数任何已有资源**零扣除**。

**角色与装备**

- A4：完成 1 组学习后，攻击力 ≥ +1（力量手套生效），主页可见。
- A5：强度与学习量正相关：完成 3 组学习后击败同种怪所需攻击次数 < 完成 1 组时所需次数。

**战斗**

- A6：进入战斗页 5 秒内，左右移动、跳跃、攻击三项操作全部可用。
- A7：怪物只从左右两侧进场；开局 10 秒内至少遭遇 1 只怪；陆军贴地行走，空军沿固定高度直线飞行。
- A8：难度可感知递增：第 3 波怪的强度高于第 1 波。
- A9：角色被击败后 3 秒内出现结算页；点「再来一局」立即重开，历史记录与角色资产零损失。

**分数与称号**

- A10：单局结束后分数与波数写入本地记录，刷新页面后仍在。
- A11：主页显示本周累计分与最高单局分；跨自然周时累计分自动重置，最高分保留。
- A12：本周累计分达 50 分时「学习王」解锁；达 150 分时「手法王」解锁；已解锁称号跨周保留，不随累计分重置消失；主页可自选 1 个称号展示并支持自定义文字。
- A13：学习页可自选目标词组（词库内至少 2 组可选），选定后本组题目全部出自该词组。

## 六、开放问题

> 挂起原则：不影响 P0 验收的问题先挂起，定案后更新到对应章节。

1. **装备具体条目清单**（名称、加成、外观）——作者待补创意；P0 先以「力量手套（攻击 +1）」占位跑通。
2. **称号档位与玩梗文案**——50/150 分为初值；「学习王」「手法王」之外还有哪些、文案怎么好笑，待定。
3. **内置词库规模**——先用约 50 词（单词 + 释义 + 干扰项），扩充规模待定。
4. **战斗数值**——各波怪的血量/速度/数量、攻击冷却等，开发期定，只需满足 A5/A8 的可感知递增。
